Forest Type Downloader

Copernicus Forest Type map, 10 m, whole of Europe. Saved straight into a folder, ready for QGIS.

This page needs Google Chrome or Microsoft Edge (on Mac or Windows) to save files into a folder. Safari and Firefox can't do that. Please open this same link in Chrome.

1Copernicus Data Space login

No account? Create one free at dataspace.copernicus.eu. The password goes only to Copernicus's own login server and is never stored.

3Download

You'll be asked to pick a folder (for example Downloads) and allow the page to save there. A sub-folder per year is created. Keep this tab open until it finishes.

Ready.
  1. Open QGIS and drag Europe_ForestType_<year>.vrt from the year folder onto the map: all of Europe as one coloured layer.
  2. Single tiles (.tif) also open on their own, already coloured.
  3. The .vrt stitches the tiles together but needs them next to it. Need one single .tif file instead? Make it in QGIS (a few clicks).
Details
Legend: 0 = non-forest, 1 = broadleaved forest, 2 = coniferous forest, 255 = outside area. Projection ETRS89 / LAEA Europe (EPSG:3035); the overseas tiles GF, GP, MQ, RE, YT are in UTM and not part of the mosaic.
Data: CLMS High Resolution Layer Forest Type, served by the Copernicus Data Space Ecosystem. Unofficial helper tool, not affiliated with Copernicus. Interrupted? Press download again with the same folder: tiles already saved are skipped.
